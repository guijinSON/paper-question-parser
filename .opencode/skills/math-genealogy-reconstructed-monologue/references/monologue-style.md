# Reconstructed monologue style contract

## Artifact class

`monologue.md` is a reconstructed discovery transcript, not a report summary.

It must be independently readable prose, but it remains downstream of the factual bundle.

## Required style rules

- write in present tense
- open with live reading of the top paper rather than with a summary of the final answer
- use first person singular notebook voice
- make the top-paper opening concrete by reacting to actual quoted passages from the factual bundle
- include actual quoted passages from the top paper and any directly read supporting paper that the factual bundle marked quote-eligible
- include 3-4 explicit attempted routes, not one smooth retrospective line
- include at least one hypothesis revision
- include at least one absurd moment that changes the question
- keep the prose independently readable without requiring the reader to cross-check `report.md`
- target 10k-20k tokens for a full compliant monologue

## Required narrative beats

1. Start by reading the actual top paper and noticing a concrete pressure point through an actual quoted passage.
2. Move through multiple hypotheses, false starts, local confusions, and self-corrections.
3. Show route changes in real time rather than flattening them into hindsight.
4. Let the eventual reconstructed question emerge through the search, not as the first sentence.

## Quote rule

When the monologue uses actual quoted passages, they must be drawn from quote-eligible claims in the factual bundle. Do not substitute vague paraphrases when the contract requires a quote-bearing moment.

## Tone boundary

- no publicity prose
- no bland retrospective summary
- no vague instruction like "be more reflective"
- no claim to direct access to the authors' private thoughts

Any speculative bridge must still carry the required disclaimer that it is a plausible reconstruction rather than private-author fact.
